# 2025 team identification artwork

The ten WebP files are the 2025 team-logo images from Formula 1's official image
CDN, retained with their original bytes. Exact URLs and SHA-256 hashes are in
`data/team-logo-pixels.json`. The matching pixel grids and generated run meshes
let the native application display the marks without runtime image decoders or
network requests.

The marks remain the property of their respective owners. They identify the
teams represented in this educational race replay; no official affiliation is
implied. This directory does not grant a separate licence to team trademarks.
